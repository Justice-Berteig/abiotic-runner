This is a very simple endless runner based on the sleeping minigame from Abiotic
Factor. Made with C++ and raylib.

# Controls
Space to jump

# Current Features
- Infinitely scrolling ground
- Player that can jump
- Pest enemies that can collide with the player
- Game restarts on death
- Randomly spawning decorative clouds

# Planned Features
- Tree decorations
- Mountain decorations
- Rock decorations
- Grass decoration
- Better looking sky
- Sun
- Other enemies
- Lives
- UI to display lives

# Building
### For Linux:
Requires CMake and GCC.
1. Clone repository and `cd` into the folder
2. Run `cmake -B build` to create a build directory
3. `cd` into the new `/build` directory
4. Build the project with `cmake --build .`
5. Run `abiotic_runner`
